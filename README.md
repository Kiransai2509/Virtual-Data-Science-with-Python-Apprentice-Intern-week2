# Week 2: Advanced Data Visualization and Storytelling with Python

## Overview
This project focuses on advanced data visualization and storytelling using Python. The Titanic dataset is used to explore patterns, identify trends, and communicate meaningful insights through visualizations.

## Objectives
- Create at least five advanced data visualizations.
- Identify patterns and relationships in the dataset.
- Interpret trends and explain their implications.
- Communicate data-driven insights to non-technical audiences.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab
- Jupyter Notebook

## Dataset
**Titanic Dataset:** [Download CSV](https://raw.githubusercontent.com/datasciencedojo/datasets/master/titanic.csv)

The dataset contains passenger information such as age, sex, passenger class, fare, family size, and survival status.

## Visualizations
1. Survival Rate by Gender
2. Survival Rate by Passenger Class
3. Age Distribution by Survival Status
4. Fare Distribution Analysis
5. Family Size vs. Survival Rate
6. Survival Rate Heatmap by Gender and Passenger Class

## Project Workflow
1. Load the Titanic dataset.
2. Clean and preprocess the data.
3. Perform exploratory data analysis.
4. Create visualizations using Matplotlib and Seaborn.
5. Interpret patterns and trends.
6. Present findings through data storytelling.

## How to Run
1. Open the Jupyter Notebook in Google Colab.
2. Run all cells from top to bottom.
3. Review the generated charts and insights.
4. Download the generated figures from the `figures/` folder.

## Expected Outcome
The project demonstrates how visualization techniques can reveal meaningful patterns in data and help communicate insights clearly for data-driven decision-making.
